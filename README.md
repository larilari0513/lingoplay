# LingoPlay 0.2.1 — 게임 번역기

게임 화면의 글자, 채팅, Discord 음성을 AI API로 번역하는 데스크톱 앱입니다. 한국어↔영어가 기본이며 설정에서 언어를 바꿀 수 있습니다.

## 0.2.1 변경 사항

- 기본 화면·문장 번역을 **GPT-6 Luna**로 업데이트했습니다. 이전에 저장한 균형 프로필도 새 모델을 사용하며 언어·장치·용어집은 유지됩니다.
- 표준 단가와 캐시 읽기·쓰기 비용 계산을 갱신했습니다. Luna의 추론은 계속 끕니다.
- GPT-4o mini가 이제 Luna보다 비싸므로 기존 ‘텍스트 절약’ 선택지를 **4o mini · 비교용**으로 표시합니다. 이미 선택한 모델 조합은 유지하며 설정에서 균형으로 바꿀 수 있습니다.
- 화면은 계속 클라우드 AI가 읽습니다. 새 Luna의 세부 이미지 크기 규칙은 공식 표에 아직 없어 `detail: auto`로 모델 기본 처리를 사용합니다. 화면 영역 선택·크기 제한은 유지합니다.

## 0.2 변경 사항

- **로컬 OCR 없이** 선택한 화면을 클라우드 AI가 읽고 번역합니다. 별도 문자 인식 모델이나 실행 프로그램을 설치하지 않습니다.
- 기본 번역은 **GPT-5.6 Luna**로 변경하고 추론을 끕니다. 설정에서 텍스트 절약 방식이나 기존 GPT-4.1 mini로 바꿀 수 있습니다.
- 상대방 듣기는 **절약 모드**가 기본입니다. 말이 끝난 구간만 음성 인식 → 문장 번역하고, 기존 실시간 모드도 선택할 수 있습니다.
- 같은 요청 재사용, 게임 용어집, 직전 대화 문맥, 이번 실행의 예상 비용 표시를 추가했습니다.

0.2의 실제 게임 번역 품질·API 지연은 아직 비교 검증하지 않았습니다. 기본 모델은 비용과 기능을 기준으로 정한 후보이며, 아래 평가 도구로 실제 사용 사례를 비교할 수 있습니다.

- Windows x64: `LingoPlay-0.2.1-Windows-x64.zip`

## 실행

- **Mac Apple Silicon:** ZIP을 풀고 `LingoPlay-darwin-arm64/LingoPlay.app`을 **응용 프로그램** 폴더로 옮겨 엽니다. 동기화 폴더의 메타데이터가 서명 검증에 영향을 줄 수 있어 iCloud Drive 안에서 직접 실행하지 않는 편이 좋습니다.
- **Windows x64:** ZIP을 **전체 압축 해제**한 뒤 `LingoPlay.exe`를 실행합니다. EXE 옆의 파일·폴더도 함께 있어야 합니다.
- **소스:** Node.js 22 이상에서 `npm ci`, `npm start`를 실행합니다.

공개 개발 미리보기입니다. Mac 버전은 로컬 실행용 서명을 적용했으며 Apple 공증·공개 배포용 서명은 하지 않았습니다. Windows 실행 패키지는 생성했지만 Windows 실기기에서는 아직 검증하지 않았습니다.

## 먼저 설정할 것

1. 왼쪽 아래 **설정 및 API 연결**에서 자신의 OpenAI API 키를 입력하고 **키 저장**을 누르면 연결을 자동 확인합니다. 모델 목록 확인은 무료이며, 실제 번역 성공 여부는 잔액·모델 권한에 따라 달라집니다. 개발 환경에서는 환경 변수 `OPENAI_API_KEY`도 지원합니다. Finder에서 앱을 열면 터미널 환경 변수는 상속되지 않을 수 있습니다.
2. **읽고 듣는 언어**, **말하고 쓰는 언어**를 고릅니다. 게임 이름과 용어집은 화면·채팅·내 음성·절약 모드 상대방 번역에 적용됩니다. 상대방의 실시간 음성 API에는 임의의 용어집 프롬프트를 전달하지 않습니다.
3. 화면 번역에는 화면 기록 권한, 음성에는 마이크 권한이 필요합니다. 앱에서 해당 기능을 처음 시작할 때 요청합니다. Mac에서 거절했다면 시스템 설정의 개인정보 보호 및 보안에서 LingoPlay를 허용하고 앱을 다시 실행하세요.

API 키는 앱의 메인 프로세스에서만 사용하며 설정에 저장할 때 macOS Keychain/Windows DPAPI 기반 Electron safeStorage로 암호화합니다. 키가 소스나 배포 패키지에 포함되어 있지 않습니다.

## 게임 화면 번역

1. **화면 선택**에서 게임 창을 선택합니다. 창이 최소화되어 있으면 화면을 가져오지 못할 수 있습니다.
2. 미리보기에서 대사·설명이 있는 영역을 드래그합니다. 작은 영역은 글자 인식과 비용에 유리합니다.
3. **한 번 번역** 또는 **자동 번역**을 누릅니다. 이미지 속 문자 인식과 번역은 AI가 함께 처리합니다.
4. **자막 창 열기**로 별도 자막을 표시합니다. 상단 막대를 드래그해 이동하거나 창 크기를 조절합니다.
5. 자막의 **잠금**은 클릭을 게임으로 통과시킵니다. 메인 창의 **잠금 해제**로 다시 이동할 수 있습니다.

자동 번역은 이전 처리가 끝난 후 선택한 간격으로 화면을 확인합니다. 변화가 작으면 요청을 건너뛰고 같은 입력은 메모리 캐시를 재사용합니다. 작은 영역의 변화도 확인하고, 변화가 작더라도 마지막 성공 후 30초가 지나면 다음 확인 시 다시 검사합니다. 동일 이미지·언어·모델·용어집이면 결과를 재사용합니다. 변화 감지는 근사치이므로 즉시 확인하려면 **한 번 번역**을 누르세요. 전체 화면의 움직이는 배경을 선택하면 API 호출이 늘어날 수 있습니다. 번역 자막 자체가 캡처 영역에 들어오지 않게 배치하세요.

독점 전체 화면에서 자막이 보이지 않으면 게임을 무테 창모드로 실행하세요. 화면 속 원문을 지우고 같은 자리에 완벽하게 합성하는 방식은 구현하지 않았으며, 번역은 별도 자막 창에 표시합니다.

## Discord 양방향 음성

Discord 데스크톱 앱과 가상 오디오 장치를 사용합니다. 번역기를 쓰지 않는 상대방은 평소처럼 Discord만 사용하면 됩니다. 서버 봇이나 Discord 계정 토큰은 필요하지 않습니다.

양방향으로 연결하려면 **분리된 가상 오디오 경로 A, B 두 개**가 필요합니다. Windows/macOS용 [VB-CABLE A+B](https://vb-audio.com/Cable/) 등이 제공하는 장치를 사용할 수 있습니다. 가상 오디오 드라이버는 이 앱에 포함하지 않았으며 설치하거나 시스템 기본 장치를 자동 변경하지 않습니다. 장치의 이름과 설치 조건은 공급업체 안내를 확인하세요.

| 설정 위치 | 선택할 장치 |
|---|---|
| LingoPlay → 내 마이크 | 실제 마이크 |
| LingoPlay → 번역 음성 출력 | A의 **재생** 장치 (예: CABLE-A Input) |
| Discord → 입력 장치 | A의 **녹음** 장치 (예: CABLE-A Output) |
| Discord → 출력 장치 | B의 **재생** 장치 (예: CABLE-B Input) |
| LingoPlay → 디스코드 수신 장치 | B의 **녹음** 장치 (예: CABLE-B Output) |
| 운영체제 기본 출력 | 실제 헤드폰 |

**Input/Output이라는 제품 이름보다 ‘재생 장치/녹음 장치’ 구분을 우선하세요.** 가상 케이블은 재생 장치로 들어온 소리를 연결된 녹음 장치에서 읽는 구조입니다.

- **오디오 장치 연결**로 마이크 권한을 부여하고 목록을 갱신합니다. 이 단계에서는 장치를 확인한 뒤 임시 마이크 스트림을 닫고 API에는 보내지 않습니다.
- **상대방 번역 시작**을 누르면 Discord 수신 음성을 선택한 언어의 자막으로 표시합니다. 여러 사람이 동시에 말하면 섞인 음성이 들어오므로 사람별 이름을 구분하지 않습니다.
- **절약 · 문장 단위 자막**은 약 0.55초의 쉼 또는 최대 6초마다 구간을 나눠 서버에서 인식·번역합니다. 조용한 구간은 보내지 않으며 배경음은 말소리로 잘못 감지할 수 있습니다. 작은 목소리·끊김 없는 발화·시끄러운 환경에서는 인식과 문장 경계가 부정확할 수 있습니다. 이전 원문 두 구간을 문맥으로 사용하고, 잡음 때문에 빈 결과가 나오면 다음 구간을 계속 듣습니다. 네트워크가 느려 대기열이 쌓이면 중지하고 안내합니다.
- **실시간 · 기존 방식**은 `gpt-realtime-translate`로 연속 번역합니다. 절약 모드의 문장 단위 대기가 불편할 때 선택할 수 있습니다. 모드는 수신을 중지한 상태에서 바꿉니다. 더 비싼 방식으로 자동 전환하지 않습니다.
- **원래 목소리도 듣기**를 켜면 기본 출력 장치로 원음도 재생합니다. 기본 출력은 실제 헤드폰이어야 합니다.
- **선택한 출력으로 AI 번역 음성 보내기**를 켜고 **말하기 시작**을 누르면 내 말을 받습니다. 한 번 더 눌러 **말하기 끝**을 누르면 원문 인식 → 번역 → 음성 생성 순서로 처리한 뒤 지정한 출력으로 전달합니다. 한 번에 최대 20초이며 문장을 짧게 나누면 대화하기 좋습니다. 처리 시간이 추가되며 원문과 번역을 함께 확인할 수 있습니다. 최초 실행에서는 송출이 꺼져 있습니다.
- Discord에서 Push-to-Talk를 쓴다면 번역된 음성이 나오는 동안 Discord의 송신 키도 유지해야 합니다. 테스트할 때는 가상 입력의 음성 감지 모드를 사용하는 편이 간단합니다.
- **모두 중지**는 마이크·수신·대기 중 API 요청·예약된 음성 재생을 중단합니다. 앱을 닫아도 종료됩니다.
- 가상 장치가 없어도 실제 마이크를 고르고 송출 체크를 끈 상태에서 **내 말 → 외국어 자막**을 시험할 수 있습니다.

사용자 자신의 말과 상대방 수신에 같은 입력 장치를 선택하지 마세요. 번역 음성이 다시 수신되는 오디오 경로는 반복 번역을 만들 수 있습니다. 장치 이름만으로 임의의 외부 라우팅을 완전히 검증할 수는 없으므로 위 표대로 분리해 주세요.

## 채팅

문장을 입력하고 **번역하기**를 누릅니다. 결과를 복사해 게임이나 Discord 채팅창에 붙여넣고 직접 전송합니다. 한국어 입력 외 다른 원문 언어도 자동 감지합니다. 자동 채팅 전송은 하지 않습니다.

## 단축키

| 동작 | Mac | Windows |
|---|---|---|
| 말하기 시작 / 끝 | ⌘ Shift Space | Ctrl Shift Space |
| 선택 화면 한 번 번역 | ⌘ Shift S | Ctrl Shift S |
| 자막 표시 / 숨기기 | ⌘ Shift O | Ctrl Shift O |
| 긴급 모두 중지 | ⌘ Shift Esc | Ctrl Shift Esc |
| 입력한 채팅 번역 | ⌘ Enter | Ctrl Enter |

다른 앱이 단축키를 선점했다면 안내가 표시됩니다. 같은 기능의 화면 버튼을 사용하세요.

## 비용·데이터·제약

설정의 **번역 방식 선택**에서 바꿀 수 있습니다. 기존 언어·장치·용어집 설정은 유지됩니다.

| 방식 | 화면 인식 + 번역 | 채팅·인식된 음성의 번역 |
|---|---|---|
| 균형 · 기본값 | GPT-6 Luna | GPT-6 Luna |
| 4o mini · 비교용 | GPT-6 Luna | GPT-4o mini |
| 기존 방식 | GPT-4.1 mini | GPT-4.1 mini |

GPT-6 Luna의 현재 텍스트 단가는 GPT-4o mini보다 낮습니다. 비교용 프로필도 화면은 Luna를 사용합니다. 이미지 비용은 실제 입력 토큰 수에 따라 달라집니다. Luna에는 `reasoning.effort: none`을 명시합니다. 모델 접근 오류는 사용자에게 알리며, 조용히 다른 모델로 재시도해 중복 비용을 만들지 않습니다.

2026-09-24 공식 표준 API 요금 기준, USD·세금 제외:

| 모델 | 입력 / 캐시 입력 / 출력 (100만 토큰당) |
|---|---|
| GPT-6 Luna | $0.10 / $0.01 / $0.50 |
| GPT-4o mini | $0.15 / $0.075 / $0.60 |
| GPT-4.1 mini | $0.40 / $0.10 / $1.60 |

- GPT-6 Luna 캐시 쓰기는 100만 토큰당 $0.125입니다. 입력이 272,000토큰을 넘으면 입력·캐시 요금은 2배, 출력은 1.5배이며 전체 요청에 적용합니다. 앱은 API가 반환한 캐시 쓰기 토큰도 계산합니다.
- 절약 음성 인식은 `gpt-4o-mini-transcribe`: **전송 오디오 1시간당 약 $0.18 + 문장 번역비**입니다. 실제 인식 요금은 토큰 기반이며 분당 $0.003은 공식 추정치입니다. 무음 제거율과 문장 길이에 따라 플레이 1시간의 비용은 달라집니다.
- 실시간 모드는 `gpt-realtime-translate`: **전송 오디오 1시간당 $2.04**입니다. 지속 수신 중에는 조용한 오디오도 전송됩니다. 두 모드의 비용 차이를 번역 품질이나 전체 비용의 절감률로 단정할 수는 없습니다.
- 내 음성은 `gpt-4o-mini-transcribe` → 선택 모델의 번역 → 송출을 켠 경우에만 `gpt-4o-mini-tts`를 호출합니다. TTS는 텍스트 입력 $0.60 / 음성 출력 $12.00 (각 100만 토큰당)이며 이 앱의 PCM 응답에는 토큰 사용량이 없어 **합계에서 제외**하고 미산정으로 표시합니다.
- 하단 **이번 실행 · 예상 비용**을 누르면 화면·문장·음성별 비용과 재사용 횟수를 볼 수 있습니다. 번역은 응답의 사용 토큰과 캐시 읽기·쓰기, 음성은 전송 길이로 계산합니다. 취소·통신 실패 뒤 서버 처리 여부가 불명확한 번역 요청도 미산정으로 표시합니다. 앱을 종료하면 초기화되며 청구서가 아닙니다. 실제 비용은 [OpenAI 사용량](https://platform.openai.com/usage)에서 확인하세요.
- 단가 출처: [Luna](https://developers.openai.com/api/docs/models/gpt-6-luna), [GPT-4o mini](https://developers.openai.com/api/docs/models/gpt-4o-mini), [GPT-4.1 mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini), [음성 및 전체 요금](https://developers.openai.com/api/docs/pricing). 단가가 바뀌면 `src/models.cjs`와 `src/usage.cjs`를 갱신해야 합니다.

- 원음·화면은 시작한 기능에서만 OpenAI로 전송됩니다. 화면 선택 미리보기는 로컬 처리입니다. 번역 API 요청에는 `store:false`를 사용하지만 이것이 제공업체의 모든 로그 보관을 없애는 의미는 아닙니다. [OpenAI 데이터 정책](https://developers.openai.com/api/docs/guides/your-data)을 참고하세요.
- 녹음·화면 이미지·번역 기록을 앱이 디스크에 자동 저장하지 않습니다. 메모리의 번역 기록과 캐시는 종료 시 삭제됩니다. 복사한 내용은 운영체제 클립보드에 남습니다.
- 번역 음성은 AI 합성 음성입니다. 실제 목소리 복제 기능은 없습니다.
- 네트워크와 언어에 따라 지연·오역이 발생합니다. API 접근 권한과 과금 한도가 필요합니다. API가 원문 자막을 제공하지 않는 경우 번역문만 표시됩니다.
- 게임별 글꼴, 움직이는 배경, 아주 작은 글자, 전체 화면 모드의 호환성은 달라질 수 있습니다. 첫 대상 게임과 실제 Discord 환경을 정한 뒤 추가 검증이 필요합니다.

## 검증 및 개발

`npm run check`로 JavaScript 문법·화면 요소 연결을 검사하고, `npm test`로 캐시 격리·요청 취소·오디오 큐·PCM 처리 등을 검증합니다. `OPENAI_API_KEY`를 환경에 제공하고 `npm run smoke:api -- /path/to/test.png`를 실행하면 **유료 API 테스트**를 수행합니다. 테스트는 합성된 샘플 음성으로 절약 모드와 실시간 모드를 검사하며 Discord로 전송하지 않습니다.

`npm run package:mac`, `npm run package:win`을 순서대로 실행하면 저장소의 `dist/` 폴더에 패키지가 생성됩니다. Mac 빌드의 로컬 서명은 생성된 앱에 `codesign --force --deep --sign - LingoPlay.app`을 적용합니다. 공개 배포용 서명·공증은 별도 단계입니다. iCloud 등 동기화 폴더에서 Finder 메타데이터 때문에 로컬 서명이 실패하면, 생성한 앱만 임시 폴더로 `ditto --norsrc --noextattr`로 복사하여 서명·검증하고 그곳에서 ZIP으로 묶으세요.

### 모델 비교

`npm run eval:models -- --dry-run --limit 20`은 포함된 게임 문장 20개와 요청 수를 무료로 검증합니다. API 키를 설정하고 `--dry-run`을 빼면 세 모델에 총 60회 **유료 요청**을 보내고 `artifacts/model-eval-*.json`에 결과·응답 시간·사용 토큰·추정 비용을 저장합니다. 기본값은 10문장입니다. `--profiles balanced,compatible`로 후보를 줄이고 `--limit 3`으로 먼저 시험할 수 있습니다.

실제 사례는 `--dataset /path/to/cases.json`으로 전달합니다. 형식은 `test/fixtures/translation-eval.json`을 참고하세요. 화면 사례는 `text` 대신 데이터 파일 기준의 `imagePath`(PNG/JPEG)를 지정합니다. 같은 화면 모델을 쓰는 프로필은 중복 호출하지 않습니다. 보고서는 원문·번역을 포함하므로 `artifacts/`는 Git에서 제외합니다.

각 사례의 `review`를 기준으로 **부정·좌우 방향·숫자·고유명사·게임 용어·자연스러움**을 사람이 평가하세요. 합성 20문장만으로 실제 게임의 품질 순위를 주장하지 않습니다. 실사용 대사·화면을 추가하고 같은 네트워크에서 반복 측정한 뒤 기본 모델 변경 여부를 판단하세요.
